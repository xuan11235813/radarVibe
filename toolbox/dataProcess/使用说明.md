# dataProcess 使用说明

读取 `receiveData` 生成的 CSV，对 ch6、ch7 进行按周期处理。公共数据处理与算法位于 `lib/dataprocess`，工具入口位于 `toolbox/dataProcess`。

## 构建与运行

在仓库根目录构建：

```sh
go build -o toolbox/dataProcess/dataProcess.exe ./toolbox/dataProcess
```

本说明中的 `./dataProcess` 命令在 `toolbox/dataProcess` 目录下通过 Git Bash 执行。PowerShell 使用 ` .\dataProcess.exe`，例如：

```powershell
.\dataProcess.exe filename.csv splitChannel
```

也可以在仓库根目录直接运行源码：

```sh
go run ./toolbox/dataProcess filename.csv splitChannel
```

- 输入路径可以是绝对路径或相对于当前工作目录的路径，含空格时使用双引号。
- 所有结果写入**当前工作目录**，不会自动放到输入文件或程序所在目录。
- 输出不覆盖已有同名文件。再次运行前，请移动或手动删除原结果，或更换工作目录。
- 查看帮助：`./dataProcess --help`。
- 成功退出码为 `0`；参数、输入、处理或保存失败为 `1`。

## 公共输入格式

输入必须包含以下表头，支持列顺序变化及额外列：

```csv
period_index,sample_in_period,ch6,ch7
```

| 字段 | 含义 |
| --- | --- |
| `period_index` | 从 0 开始的周期编号 |
| `sample_in_period` | 从 0 开始的周期内采样索引 |
| `ch6` | 通道 6 的数值 |
| `ch7` | 通道 7 的数值 |

支持 UTF-8 BOM、字段两侧空格及有限浮点数；内存中的通道数据使用 `float64`。

数据须按周期及周期内采样顺序排列：周期编号从 0 开始且连续，每个周期的采样索引从 0 开始且连续。重复、乱序、周期内索引缺失、缺列、无数据或非法数值会报错，不自动补零。

完整周期包含 **2125 个采样点**。两个功能都先丢弃不完整周期，再截取采样范围；即使不完整周期足够覆盖所选范围，也不会保留。没有完整周期时返回错误。

## 功能一：splitChannel — 拆分通道矩阵

将 ch6、ch7 分别整理为 `[周期][采样]` 二维矩阵，输出纯数值 CSV。

### 命令与参数

```sh
./dataProcess filename.csv splitChannel [start end]
```

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `filename.csv` | 必填 | 输入 CSV 路径 |
| `start` | `0` | 周期内起始索引，包含此点 |
| `end` | `2124` | 周期内结束索引，包含此点 |

`start`、`end` 必须成对给出，满足 `0 <= start <= end < 2125`。每行保留 `end-start+1` 个点。

### 示例

```sh
# 保留每个完整周期的全部 2125 个采样点
./dataProcess filename.csv splitChannel

# 保留索引 100～500，共 401 个点
./dataProcess filename.csv splitChannel 100 500

# 只保留每个完整周期的最后一个采样点
./dataProcess filename.csv splitChannel 2124 2124
```

### 处理流程

1. `ReadCSV`：读入 `[]Sample`。
2. `ToMatrices`：形成 ch6、ch7 的 `[][]float64`，此时保留不完整周期。
3. `SelectSamples`：筛选完整周期并截取闭区间 `[start,end]`，结果具有独立存储。
4. `SaveMatrices`：保存两个通道矩阵。

### 输出文件

| 文件 | 内容 |
| --- | --- |
| `datach6.csv` | ch6 采样矩阵 |
| `datach7.csv` | ch7 采样矩阵 |

文件**无表头、无索引列**，每行代表一个保留周期，每列代表一个选中采样点，均按原顺序排列。

标准 `receiveData` 单帧包含 246 个完整周期和末尾 1538 个点的不完整周期，因此默认输出为 **246 行 × 2125 列**；选择 `100 500` 时为 **246 行 × 401 列**。

保存失败时，会清理本次创建的输出文件，保留原有文件。

## 功能二：fftChannel — 按周期计算通道 FFT

对 ch6、ch7 所选采样矩阵逐行计算 FFT，并分别保存完整复数频谱及实部、虚部文件。

### 命令与参数

```sh
./dataProcess filename.csv fftChannel [start end] [removeDC]
```

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `filename.csv` | 必填 | 输入 CSV 路径 |
| `start` | `0` | 周期内起始索引，包含此点 |
| `end` | `2124` | 周期内结束索引，包含此点 |
| `removeDC` | `true` | `true`：变换前减去均值；`false`：保留直流 |

`start`、`end` 必须成对给出，满足 `0 <= start <= end < 2125`。`removeDC` 只能使用 `true` 或 `false`，允许省略采样范围而单独指定此参数。

### 示例

```sh
# 全部采样，逐行去直流
./dataProcess filename.csv fftChannel

# 全部采样，保留直流
./dataProcess filename.csv fftChannel false

# 截取 100～500，逐行去直流
./dataProcess filename.csv fftChannel 100 500

# 截取 100～500，保留直流
./dataProcess filename.csv fftChannel 100 500 false
```

### 处理流程

1. `ReadCSV`：读取输入文件。
2. `ToMatrices`：生成 ch6、ch7 周期矩阵。
3. `SelectSamples`：丢弃不完整周期并截取采样范围。
4. `FFTRealRows`：对两个通道分别逐行执行 FFT。
5. `SaveComplexMatrix`：保存完整复数频谱。
6. `SaveComplexMatrixParts`：将同一频谱拆分保存为实部和虚部 CSV。

### FFT 约定

- 去直流均值针对**截取后的每一行**独立计算。
- 仅沿第二维变换，不跨周期计算。
- 不自动补零、不加窗、不归一化、不执行 `fftshift`。
- 每行返回 `N=end-start+1` 个频点，包含正负频率的完整频谱，索引 0 为直流。

### 输出文件

| 文件 | 内容 |
| --- | --- |
| `fftch6.txt` | ch6 完整复数频谱，元素形式如 `(1+2i)` |
| `fftch6_real.csv` | ch6 频谱实部 |
| `fftch6_img.csv` | ch6 频谱虚部 |
| `fftch7.txt` | ch7 完整复数频谱 |
| `fftch7_real.csv` | ch7 频谱实部 |
| `fftch7_img.csv` | ch7 频谱虚部 |

所有文件**无表头**，每行对应一个保留周期，每列对应一个频率 bin。标准单帧默认每个文件为 **246 行 × 2125 列**；选择 `100 500` 时为 **246 行 × 401 列**。

该功能只生成上述六个文件。执行前检查全部目标文件，任意一个已存在即报错，不开始写入。若写入过程中发生磁盘等错误，已成功保存的文件可能保留；处理这些文件后再重新运行。

## 代码位置与验证

| 位置 | 职责 |
| --- | --- |
| `lib/dataprocess/csv.go` | CSV 读取、实数矩阵保存 |
| `lib/dataprocess/matrix.go` | 周期矩阵转换、完整周期筛选及采样截取 |
| `lib/dataprocess/fft.go` | FFT 公共算法 |
| `lib/dataprocess/complex.go` | 完整复数矩阵读写 |
| `lib/dataprocess/complex_parts.go` | 实部、虚部分离读写 |
| `toolbox/dataProcess/main.go` | 命令参数解析及功能调用 |
| `test/dataprocess_test.go` | 基础处理函数测试 |
| `test/dataprocess_cli_test.go` | 工具命令行端到端测试 |
| `test/fft_test.go` | FFT 数值与边界测试 |

周期长度复用 `lib/radar.SamplesPerPeriod`。在仓库根目录运行：

```sh
go test ./...
go vet ./...
```

需要重新执行并查看命令行测试详情时：

```sh
go test ./test -run TestDataProcessFFTCLI -count=1 -v
```

命令行测试结果保留在 `test/results` 下的独立目录，可查看并手动删除。
